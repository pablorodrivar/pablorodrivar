#### 🎼 Currently building: [Codetta](https://getcodetta.app)

A sheet music app for musicians: read, annotate and organise scores on a tablet, fully offline, with a web app to manage your library.

- **Mobile:** Expo / React Native (New Architecture), native PDF rendering modules in Swift (PDFKit) and Kotlin (PdfRenderer), Apple Pencil annotation with Skia
- **Web:** Next.js on Cloudflare Workers, Tailwind, pdf.js
- **Backend:** Supabase (Postgres with row-level security, Auth, Edge Functions), PowerSync for offline-first sync, Cloudflare R2
- **Engineering:** pnpm + Turborepo monorepo, strict TypeScript, Zod at every boundary, Vitest, pgTAP and Playwright tests, architecture decision records, CI on GitHub Actions
- Performance-driven: page turns under 50 ms, measured on real devices

The Codetta repository is private for now. Happy to walk you through the code, just get in touch.
